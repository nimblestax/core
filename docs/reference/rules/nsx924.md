## What it checks

`nsx test` found no Preview Environment of this project to run Tests on.

## Why

Tests run on the tables a Preview Environment built, so the preview must be deployed, and its refresh must have succeeded, first. Nimblestax knows it did when the preview's Deployment Manifest is in its bundle folder. It exits 2.

## Example

You haven't run `nsx preview` yet. In a project, this fails:

```console
$ nsx test
```

## Fix

Run `nsx preview`, or `nsx preview --pr <number>` for a pull request's preview, then `nsx test` again.
