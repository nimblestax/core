## What it checks

Databricks publishes no CLI for this operating system and architecture.

## Why

Nimblestax downloads the Databricks CLI archive for this machine. Databricks publishes one for Linux, macOS and Windows, each on x86-64 and ARM, and nothing else.

## Example

Nimblestax runs on 32-bit Linux. In a project, this fails:

```console
$ nsx deploy --env dev
```

## Fix

Build or install a Databricks CLI for this machine and point `NIMBLESTAX_DATABRICKS_CLI` at it.
