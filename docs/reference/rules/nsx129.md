## What it checks

A Nimblestax Skill in `.agents/skills/` or `.claude/skills/` was written by another version of Nimblestax than the one installed.

## Why

Nimblestax Skills guide a coding agent through Nimblestax's commands, and each one records the Nimblestax version that wrote it. A skill from another version can name commands, options or steps the installed Nimblestax doesn't have, so an agent follows stale steps. This is a warning: `nsx validate` still passes.

## Example

Write this file into the project `nsx init` creates, and `nsx validate` warns:

`.agents/skills/nimblestax-add-source/SKILL.md`:

```markdown
---
name: nimblestax-add-source
description: Add a Source to a Nimblestax project.
metadata:
  nimblestax-version: "0.0.9"
---

# Add a Source
```

## Fix

Run `nsx skills update`, which refreshes both copies of each skill, and commit them.
