## What it checks

A config file has no `version`.

## Why

A Kind's schema can change between Nimblestax releases. `version` says which schema a file is written against, so a newer Nimblestax reads an older file as it was meant.

## Example

Write this file into the project `nsx init` creates, and `nsx validate` fails:

`domains/sales/sources/orders.yaml`:

```yaml
kind: source
path: /Volumes/{env}_sales/bronze/landing/orders
format: json
```

## Fix

Add `version` below `kind`, with the latest version this Nimblestax supports, such as `version: 1`.
