## What it checks

`nsx init` wrote Nimblestax Skills into a folder Git ignores, such as `.claude/`.

## Why

Nimblestax Skills are committed, so everyone on the team, and CI, gets the same version, and a change to a skill is reviewed in a pull request. In a folder Git ignores, the skills stay on one machine. This is a warning: `nsx init` still succeeds.

## Example

The repo's `.gitignore` lists `.claude/`. In a project, this warns:

```console
$ nsx init
```

## Fix

Stop ignoring the folder the diagnostic names, or only its `skills/nimblestax-*` folders, with a line such as `!.claude/skills/` in `.gitignore`, then commit them.
