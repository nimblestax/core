## What it checks

This Nimblestax doesn't support that `version`.

## Why

The file is written against a schema this Nimblestax doesn't have, usually because a newer Nimblestax wrote it. Checking it against another version's schema would give wrong answers.

## Example

Write this file into the project `nsx init` creates, and `nsx validate` fails:

`domains/sales/sources/orders.yaml`:

```yaml
kind: source
version: 2
path: /Volumes/{env}_sales/bronze/landing/orders
format: json
```

## Fix

Use a version this Nimblestax supports, which the diagnostic lists. If the file needs a newer Nimblestax, upgrade Nimblestax in the project so everyone runs the same one.
