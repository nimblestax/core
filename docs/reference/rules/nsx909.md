## What it checks

`nsx init` was run in a folder that already holds `nimblestax.platform.yaml`.

## Why

`nsx init` writes a new project. Writing it over an existing one would replace the Platform Contract and every starter file you've edited, so it writes nothing instead. Other files in the folder are fine, so a new Git repo with a README works.

## Example

In a project, this fails:

```console
$ nsx init
```

## Fix

Run `nsx init` in another folder, or give it one, as `nsx init <folder>`.
