## What it checks

A raw string in a Gold Model's SQL, such as `r'${env}'`, holds `${`.

## Why

The pipeline replaces `${name}` with a setting's value anywhere in its SQL, even inside a string. Nimblestax escapes `${` in ordinary strings and comments, so they keep the value you wrote, but a raw string can't hold the escape.

## Example

Write this file into the project `nsx init` creates, and `nsx validate` fails:

`domains/sales/models/gold/fct_orders.sql`:

```sql
SELECT order_id, r'${order_id}' AS template
FROM sales.silver.orders
```

## Fix

Write it as an ordinary string, doubling each backslash, and Nimblestax escapes the `${`.
