## What it checks

The Databricks CLI Nimblestax downloaded doesn't match the checksum its release names.

## Why

Each Nimblestax release names one Databricks CLI version and the checksum of each platform's archive. Nimblestax downloads that archive from Databricks' GitHub releases the first time it needs the CLI. An archive that doesn't match was changed or cut short on the way, so Nimblestax doesn't install it and runs nothing.

## Example

A proxy between you and GitHub changes the archive Nimblestax downloads. In a project, this fails:

```console
$ nsx deploy --env dev
```

## Fix

Run the command again. If it fails again, something between you and GitHub is changing the download: check your proxy, or point `NIMBLESTAX_DATABRICKS_CLI` at a Databricks CLI you installed yourself.
