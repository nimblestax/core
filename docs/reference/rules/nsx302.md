## What it checks

With `--platform`, a schema the project's tables need isn't in its catalog in the Environment's workspace, or the identity Nimblestax signs in as can't see it.

## Why

Nimblestax makes tables in schemas that already exist, and never creates them, for the same reasons as `NSX301`. A deploy into a schema that isn't there fails halfway through, so `nsx validate --platform` checks first.

## Example

dev's workspace has the catalog `dev_sales` but no schema `silver` in it. In a project, this fails:

```console
$ nsx validate --platform
```

## Fix

Create the schema in its catalog, or grant the identity `USE SCHEMA` on it.
