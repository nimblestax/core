## What it checks

`nsx test` can't tell which SQL warehouse to run Tests on.

## Why

Tests run as SQL on a warehouse in the Development Environment's workspace, where every Preview Environment lives. With no `warehouse` set, Nimblestax uses the only one you can see there, and with several, or none, it won't guess. It exits 2.

## Example

The workspace has two SQL warehouses, and `nimblestax.platform.yaml` names neither. In a project, this fails:

```console
$ nsx test
```

## Fix

Add `warehouse` under the Development Environment in `nimblestax.platform.yaml`, set to the ID of the warehouse your team runs Tests on.
