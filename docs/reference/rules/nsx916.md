## What it checks

`nsx init --example` names an example Nimblestax doesn't ship.

## Why

`nsx init --example` writes one of the example projects that ship inside Nimblestax, so the example always matches the Nimblestax you have installed. The diagnostic lists the examples there are. It exits 2, because the command line needs a change.

## Example

In a project, this fails:

```console
$ nsx init --example teapot
```

## Fix

Name an example the diagnostic lists, such as `nsx init --example kettle`.
